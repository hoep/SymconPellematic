Oekofen JSON Interface V4.00b

usage: http://touch_ip:JSON_port/password/command

command:
  all[?]                 all available components
  error                  current errors
  log[0..3]              download logfile (CSV)
  system[?]              system global variables
  weather[?]             current weather data
  forecast[?]            weather forecast
  power[?]               power meter
  stirling[?]            stirling data
  hk[1..6][?]            heating circuit
  thirdparty[1..20][?]   third party sensors
  pu[1..3][?]            accu
  ww[1..3][?]            domestic hot water
  sk[1..6][?]            solar circuit
  se[1..3][?]            solar yield
  circ[1..3][?]          circulation pump
  pe[1..4][?]            pellematic

  append '?' to get the metadata (unit, factor, min, max, format, text)

  read a single value:  http://ip:port/pw/hk1.L_roomtemp_act
  set a value:          http://ip:port/pw/id(1..6).variable=value
                        example: hk1.mode_auto=0
                        alternative syntax: hk1_mode_auto=0

  only variables without a leading 'L_' can be set.
